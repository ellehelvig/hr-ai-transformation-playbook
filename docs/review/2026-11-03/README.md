# README review captures

Captured from the public GitHub-rendered README on 3 November 2026 with Playwright
and Chrome at 1440 x 1000 and 390 x 1000 viewport sizes. Images crop to the rendered
README article, excluding repository file lists. GitHub's overlapping sticky file
header is hidden for capture; README content is unchanged by that capture setting.

The before images show the audited main branch. The after images show this review
branch. These captures document presentation, not software reliability or legal
compliance. All HR examples shown are fictional.
